## GUI界面

### 主要特性

- **双视图布局**：左侧显示电路原理图，右侧显示物理布局
- **交互式导航**：鼠标滚轮缩放，拖拽平移
- **实时可视化**：模块颜色编码（红色=可移动，蓝色=固定，绿色=宏单元）
- **密度热力图**：显示布局密度分布
- **算法控制面板**：参数调节和一键执行

### 启动GUI

```bash
# 启动GUI应用
./eda_gui

# 直接打开文件
./eda_gui design.aux
```

### 界面组件

1. **菜单栏**
   - File: 新建、打开、保存、导出
   - Edit: 编辑操作
   - View: 视图控制
   - Placement: 布局算法
   - Tools: 工具设置

2. **工具栏**
   - 文件操作快捷按钮
   - 视图控制（缩放、适应）
   - 布局执行按钮

3. **主视图区**
   - 左侧：电路原理图画布
   - 右侧：物理布局视图

4. **停靠面板**
   - 右侧：算法控制面板
   - 底部：状态栏

5. **算法控制面板**
   - 初始布局参数设置
   - 全局布局参数设置
   - 执行控制按钮
   - 进度显示
